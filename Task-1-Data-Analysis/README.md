# Task 1: Data Analysis — Machine Downtime

## Objective
Analyze machine telemetry data from Daikibo Industrials to identify factories and device types experiencing the most downtime.

## Tools Used
- Tableau Public
- JSON dataset

## Work Completed
- Imported and explored machine telemetry data in Tableau.
- Created a calculated field to identify unhealthy machine status.
- Analyzed machine downtime by factory and device type.
- Developed an interactive Tableau dashboard to visualize the results.

## Key Findings
- Daikibo Factory Seiko recorded the highest machine downtime.
- LaserWelders experienced the most downtime among device types.

## Files
- Tableau workbook (`.twb`)
- Dashboard screenshot (`.png`)

## Learning Outcomes
Gained practical experience in data visualization, calculated fields, dashboard creation, and interpreting industrial telemetry data.

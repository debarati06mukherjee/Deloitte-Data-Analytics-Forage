# Task 2: Forensic Technology — Gender Pay Equality Analysis

## Objective
Analyze employee compensation equality scores at Daikibo Industrials to identify potential gender pay disparities across factories and job roles.

## Tools Used
- Microsoft Excel
- Excel formulas
- Data classification

## Work Completed
- Analyzed the provided employee compensation equality dataset.
- Created a new column named "Equality class".
- Classified equality scores into three categories:
  - **Fair:** Scores between -10 and +10.
  - **Unfair:** Scores between -20 and -11, or +11 and +20.
  - **Highly Discriminative:** Scores below -20 or above +20.
- Applied the classification across the dataset using Excel formulas.

## Learning Outcomes
- Data classification using conditional logic.
- Understanding gender pay equality metrics.
- Identifying potential pay disparities across job roles and factory locations.
- Working with structured datasets in Microsoft Excel.

## Deliverable
Completed Excel workbook containing the original data and the additional Equality class column.
